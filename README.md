# PUSHII

Сайт бренда зоокосметики PUSHII. Next.js App Router, TypeScript, CSS Modules и статический экспорт.

## Разработка

Требуется Node.js 24 и npm.

```sh
npm ci
npm run dev
```

## Сборка и проверки

```sh
npm run build
npm run typecheck
npm run check
npm run preview
```

Статическая сборка создаётся в `out/`. Локальное превью: http://127.0.0.1:3000.

## Публикация

GitHub Actions собирает и проверяет сайт при изменении ветки `main`, затем публикует `out/` через GitHub Pages. Домен и SEO задаются в `src/config/site.json`. Настройки Pages: источник GitHub Actions, собственный домен, HTTPS.

## Содержимое

- `src/components/sections/` — секции страницы.
- `src/data/` — тексты о средствах и FAQ.
- `src/config/site.json` — домен, SEO и контактная ссылка.
- `public/visuals/` — изображения и концептуальные макеты упаковки.
- `public/brand/` — фирменные материалы.
- `public/fonts/` — локальные шрифты Nunito и лицензия OFL.

При добавлении реальных продуктов используйте утверждённые названия, составы, объёмы, изображения и инструкции. Макеты упаковки на сайте — концептуальная визуализация. Платежи, формы сбора данных и серверная часть отсутствуют.

Исходный код доступен для просмотра. Права на название, логотип и фирменные материалы PUSHII сохраняются за правообладателем.

## SEO и аналитика

Параметры находятся в `src/config/site.json`. Сайт использует Яндекс Метрику после добровольного согласия; отказ и отзыв согласия доступны в настройках cookie. На localhost и других origin счётчик не запускается. Цели: `view_products`, `open_product_details`, `view_faq`, `click_contact`, `scroll_75`. Это события интереса, а не продажи.

`/privacy/` содержит информацию об операторе, хостинге и аналитике. При смене оператора, контактов или сервисов обновляйте текст и механизм согласия.

`npm run check` проверяет HTML, Schema.org, canonical, sitemap, иконки, страницу 404 и сценарии согласия. Иконки и социальный JPEG производятся из исходных брендовых файлов командой `node scripts/seo-assets.mjs` (использует sharp из окружения Next.js).

GitHub Pages не применяет `_headers`. Этот файл не создаётся; HTTPS и редиректы настраиваются в GitHub Pages. Не считать метатеги заменой защитных HTTP-заголовков.
